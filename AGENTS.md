# Agent guidance

This repository is public. Keep internal references out of everything you write here:
code, comments, docs, commit messages, branch names, PR titles and bodies, and review
comments. That means no issue-tracker keys or links, private repository names, internal
hostnames or account IDs, personal names or usernames embedded in identifiers (kube
contexts, AWS profiles, home-directory paths, email addresses), customer names, or
internal planning vocabulary. State the
reason for a change directly instead of pointing at an internal source.

Full guidance: [`.claude/rules/public-repo.md`](.claude/rules/public-repo.md).
